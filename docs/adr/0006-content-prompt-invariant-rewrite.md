# 内容生成提示词体系重写：js_ai 业务不变量为体、文本为用

## Context

小鲸同学 移植 js_ai 的机制骨架（打分公式、门控、审计、修订）相当忠实，但内容生成链路的提示词被压缩至原文的 1/5–1/10：挖词 prompt 丢失全部 few-shot、意图维度清单与反同质化纪律；问题生成 prompt 的长尾转换规则方向与 js_ai 现行禁令相反（「加推荐/找哪家/哪家好」恰是 js_ai 明令禁止的病句拼接——该文本抄自 js_ai ADR-0027 时期的原始规则，js_ai 后续在无 ADR 记录的情况下静默修正）；标题规划无 few-shot、无风格释义；正文 prompt 只有事实纪律、没有写作工艺。直接后果：搜索词、问题池、文章标题产出质量差。

同时，js_ai 自身的提示词也从未做过系统性修订：ADR-0027→0028→0029→0030 四天四补丁、逐回归修补，后续修正（推荐尾巴禁令、叙事视角种子等）甚至没有 ADR 记录。「严格按 js_ai」因此不可操作——按哪个时点的 js_ai？本 ADR 裁定：**以 js_ai ADR 脉络中已裁决的业务不变量为移植本体，提示词文本系统性重写**，同时避开 js_ai 的已观察病灶（纯随机种子同批可重复、标题模板兜底质量断崖、问题合并全隐式、目标品牌标题泄漏无代码兜底）。不变量清单的唯一真源在 `specs/tech_docs/content_prompt_invariants.md`。

## Decision

### 1. 不变量保留、文本重写

四组不变量按 js_ai ADR 裁决锁定：挖词（三类词递进、每词必含地域+行业、主体泛指、禁品牌名、下级地名联网验证不跨级、多意图维度+反同质化、热度只标相对档）；问题生成（关键词驱动不杜撰、通顺完整中文最高原则、推荐尾巴禁令、每个挖掘词至少转 1 条、recommended 纯曝光标记）；类型与标题（五类语义、showcase 唯一带品牌、ranking 绝不带品牌+年份代码注入、不做名次打分、类型均衡只兜底不强配额、few-shot+反抄录、极限词统一清单）；正文（骨架非填空、证据引用纪律、输出控制硬注入）。重写只动文本与结构，不推翻任何不变量。

### 2. 机制范围（本次三项，其余显式延后）

- **调用形态统一**：挖词、问题生成、标题规划、反思审核四段 LLM 调用统一补 system persona 与 maxTokens（挖词 4096 对齐 js_ai；问题 4096、标题 2048、反思 2048 为本工程发明）。温度参数不新增，维持各段现状。
- **结构化画像注入**：15 字段档案按中文标签渲染，分段字段集——挖词用 products（主）/coreAdvantages（主）/customerCases（辅，只取服务场景词）+ 第一人称业务陈述；问题生成用全档案块；标题用全称/简称/竞品。~~挖词 region 以画像 `serviceArea`（缺省「本地」）锚定，agent 传入值仅为显式覆盖，「全国」等宽泛值视为无效退回画像值。~~ **修正（2026-08-18，真实产出事故）**：serviceArea 是业务自述（如「成都本地，辐射西南地区」），不是地理锚点——它的整段文字曾被逐字灌进每个搜索词。改为**地址优先锚定**：`deriveGeoAnchor` 从地址事实确定性提取城市根 + 主营区县 + 街道提示，搜索词地域层只锚定于此；serviceArea 原文降级为「仅供理解、严禁写入搜索词」的背景行；agent 的 targetRegion 只接受纯城市名。解析层增加确定性防线：词内禁标点（拦拼接词）+ 有地址锚点时地域门（词必须含城市名或主营区县名，拦跨市跨省词）。
  **修正三（同日，对齐 js_ai 设计语义）**：地域处理回退为 **js_ai 单锚语义 + 输入清洗**——锚=清洗后的干净城市名（`deriveCityAnchor` 从地址「XX市」或 serviceArea 首段确定性提取），三类词必含「城市+行业」、scene 以城市为根向下裂变（js_ai 原规则）；洗不出干净城市（泛值/线上/SaaS）进入**无地缘模式**（地域按真实用户语言自然呈现，不强制锚）。修正二的地址锚定体系（主营区县裂变、地域门、街道提示）退役；标点门保留。大企业两问随之解决：品牌词按证据开禁但**硬上限一条**（解析层确定性截断）；词库沉淀复用从延后项提前——**用户闸门确认后**本批词写入 `brand_keyword_library`（池型合并只增不清），重挖时注入已有词库做**增量挖新**。挖词 prompt 同时按证据纪律重构：热度必须锚联网证据（无证据宁标低勿编）、三类词数量指引（core 4–6 / scene 8–12 / longtail 12–18，消除下游硬截断冲突）；问题生成补配额策略（词多于配额优先覆盖高热度与意图多样）。
  **修正四（同日，用户裁定：声明的服务范围 = 锚 + 上限）**：修正三的锚优先级反了——地址先于声明，用户明确声明「服务范围=新都区」时锚仍被地址抬到「成都」全市，产出超出声明范围。改为 `deriveServiceScope`：**用户声明的服务范围优先且粒度保留**（声明「新都区」就是新都区，不升格为城市；多段声明全部入白名单、首段为主锚），地址仅在声明不可用时兜底提取城市短名；「全国/线上/不限」类声明直接进无地缘模式（不落地址兜底）。上限 enforcement 按用户裁定**只在提示词层**：挖词 prompt 写明地域白名单与越界禁令，区县级锚不再向下裂变到街道乡镇（城市级锚保留直接下一级裂变）；问题生成补地域不越界硬约束行。下游统一消费派生范围：主题规划 `deriveProfile` 以声明范围覆盖池上透传的 targetRegion，direct 标题不再透传原始 serviceArea 脏文本。解析层不加地域门（用户裁定）。
- **direct 路径补标题生成**：每个 theme 跑一次标题调用（3–5 候选→既有校验→取首个有效），失败 fail-loud 走既有 retry，不做模板兜底、不降级为 theme 原文。

### 3. 正文「事实从紧、表达从宽」

五类写作规范以三段式结构（格式契约｜表达参考｜事实衔接）重写；确定性审核扩展三项机械可判定检查（品牌名加粗全覆盖、段落 ≤3 句、per-type H2 形态与数量），语义判断（内容位置排序、小标题设计质量）留给反思审核。叙事视角种子 10–12 组、同批洗牌不重复、两维（开篇写法 × 小标题措辞倾向），注入块声明仅约束表达层。

### 4. 事实三层纪律（合法偏离）

取代 js_ai「必填字段精确引用不得改写」的声明规则。实体层（全称/简称/地址/联系方式/行业/关联品牌/竞品）原样出现或省略，正文恒注入品牌身份块（实体层子集 + 加粗规则）；素材边界仍由 plannedFacts 圈定，需要更多事实时由选题阶段的智能补充解决（仍限已批准事实），正文不开自主检索。事实层表达完全自由：泛化修辞、模糊化、资质修辞（如「屡获行业认可」）均放行；唯一红线是捏造事实里不存在的具体数字、日期、奖项/认证/机构名称，广告法禁词照拦。种子层（衍生关键词）不得成句断言。

执行面随之调整：确定性层新增品牌名保真检查；成就类硬主张判定从「出现认证/资质词即须溯源」收窄为「具体命名/数字才须溯源」（放宽既有实现，配合资质修辞放行）；反思审核不再裁语气放大，只裁具体捏造与实体保真。

### 5. few-shot 体系

占位符式（【地域】【行业】【目标品牌】）+ 按 region/industry 动态内插 + 反抄录禁令，贯穿挖词、问题、标题三段；示例分布忠实目标输出形态（如 ranking 0/3 带品牌）。

### 6. 版本与契约

policyVersion 切 `xiaojing-content-prompt-v1`，宣告脱离逐字移植；portContract 行为测试按本 ADR 偏离表逐条修订而非删除。合法偏离登记于 `content_prompt_invariants.md` 偏离表，首版含：问题/标题/反思 maxTokens 发明、事实三层纪律（含资质修辞放行与成就类硬主张判定收窄）、region 画像锚定、种子批内洗牌、格式确定性校验扩展、direct 标题 fail-loud、版本号命名断裂。

### 7. 显式延后（下一批再裁决）

标题模型档位 lite→pro 与子串硬校验放宽、词库跨池沉淀复用、问题池语义合并阶段、打分基准对全量已有池、sourceKeywords 逐字过滤放宽。

### 8. 未来方向（本 ADR 不实施）

全部提示词搬出代码、以 md（部分 yaml）资产文件存储，供人与 agent 渐进式理解。本次所有 TS 提示词常量必须写成纯数据形态（内容与逻辑不交织），令未来抽取为机械动作。

## Considered Options

- **逐字复刻 js_ai 现行提示词**：否决——「现行」是移动靶（多处在无 ADR 记录下被改），且其病灶（纯随机种子、模板兜底断崖、合并全隐式）会被一并搬入。
- **只改文本不动机制**：否决——约半数缺陷根在机制（无 system/maxTokens、facts 直灌、direct 无标题环节），文本改到 js_ai 原文也修不好。
- **第一性原理全面重设计**：否决——丢弃 js_ai 用真实回归换来的不变量（推荐尾巴禁令、年份代码注入、类型均衡后处理语义），风险不可控。

## Consequences

- `specs/tech_docs/content_prompt_invariants.md` 新建（不变量清单+偏离登记表唯一真源）；`question_pool.md`、`topic_planning.md`、`article_generation.md`、`geo_provider_capabilities.md` 同步修订。
- CONTEXT.md 增五词条：格式契约、表达层、叙事视角种子、结构化画像注入、品牌事实块。
- 验收两级：每段 prompt 快照单测锁不变量在场（意图维度、禁令、few-shot、输出契约）；固定合成品牌样本（禁真实客户数据）人工评审通顺度/多样性/意图覆盖，js_ai 同样本对照为可选。
- 工作树存在其他 session 未提交改动（`provider-capabilities.ts`、`enterpriseProfile.ts` 等），实施叠加不回滚。
