# 工作台退化为权威产物投影，品牌级内容拆为一级入口

右侧品牌工作台不再承载任何过程状态与控制：agent 的思考推进、操作生命周期控制（暂停/恢复/重试/取消）、排队横幅与全部确认门收敛到聊天侧（闸门卡 + 进度卡）；工作台只呈现当前聚焦 GEO 操作的六阶段骨架（当前阶段展开、其余收起为一行，可点击回看）与只读产物面板。品牌级内容离开 Session 作用域，拆为左侧栏两个一级入口：**品牌档案**（知识版本史 + 产物血缘，只读）与**效果**（基线探测、监测管理、效果看板整页）。材料导入与 GEO 动作发起并入聊天（自然语言 + 空态建议词），工作台与档案均无动作入口。细节交互参照成熟 Agent 产品的既有模式（Manus 的旁侧产物投影、主流对话式 Agent 产品的流内确认卡）。

## Considered Options

- **阶段严格锁定**（工作台只渲染当前阶段的产物，其余不可见）：被否——产物是权威投影，回看（写文章时查问题池、深链定位历史步骤）是工作台存在的核心价值；锁定会把回看逼回聊天滚动。
- **过程信息留在工作台**（现状：排队横幅、operation 生命周期卡、18 步列表、控制按钮与产物面板混排）：被否——过程与产物两种信息混在同一条滚动列是「混乱」的直接来源，且与聊天进度卡重复呈现同一事实。
- **维持两个一级入口公理**（DESIGN.md 原文「应用只有主聊天和品牌工作台两个一级入口」）：被否——知识版本/产物血缘与效果观测是品牌级事实，不属于任何 Session，放在 Session 作用域的工作台里语义错位。产品结构改为四个一级入口。
- **品牌档案趁机扩展为跨 Session 操作历史**：本轮被否——是新增聚合能力而非搬迁，扩展与搬迁分离，另立后续票。

## Consequences

- `DESIGN.md` 产品结构、布局与闸门卡片节的「维持现状」条款（L39）作废重写；`material_import.md`（真实入口改聊天）、`knowledge_authority.md`、`geo_baseline.md`、`geo_operations.md`、`geo_notifications.md` 对应更新。
- 前置修复：`articles/approve` 与 `distribution-plans/confirm` 确认后补决策回执（reminder）注入——现状只记 milestone 不唤醒 agent，「选完继续推进」承诺在这两门断裂。
- 桌面通知深链落点变更：待确认门通知 → 聊天 Tab 定位到闸门卡；监测告警 → 效果入口定位到具体监测 run。
- 操作侧步骤面板遗留的非只读交互代码路径删除（自闸门卡迁移完成起即为死代码）；效果侧面板交互随新入口迁移保留。
- 工作台仅挂载于聊天 Tab；欢迎页/设置页不再挂工作台。能力启动卡删除，四个预设目标转为聊天空态建议词。
