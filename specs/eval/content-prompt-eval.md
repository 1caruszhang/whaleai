# 内容生成提示词人工评审（ADR-0006 两级验收第二级）

固定三个合成品牌样本（禁止真实客户数据）跑全链（挖词→问题池→选题标题→正文），人工评审产出质量。评审维度：**通顺度**（是否像真人会说的话）、**多样性**（问题/标题是否同质化）、**意图覆盖**（longtail 是否覆盖多意图维度）、**格式达成**（正文格式契约）。js_ai 同样本对照为可选。

## 样本 A：本地服务·画像齐全（对齐 js_ai 示例行业，便于逐段对照）

```json
{
  "fullName": "锦江区鲸鱼汽车音响经营部",
  "shortNames": ["鲸鱼音响", "鲸鱼改声"],
  "serviceArea": "成都市锦江区",
  "industry": "汽车音响改装",
  "products": ["汽车音响升级", "全车隔音降噪", "车门音响改装"],
  "coreAdvantages": ["师傅均有10年以上改装经验", "只用原厂配件", "改装后提供质保"],
  "trustEndorsements": ["2025年获区市场监管局诚信商户"],
  "customerCases": ["服务过宝马3系车主做全车隔音", "为本地三家连锁汽修店供货安装"],
  "customerPainPoints": ["改装店报价不透明", "劣质配件冒充原厂"],
  "targetCustomers": ["30-45岁私家车主", "汽修门店"],
  "competitors": ["甲乙丙丁戊己（六个合成竞品名）"],
  "derivedKeywords": ["成都 改音响", "锦江 隔音"]
}
```

评审要点：scene 词应出现锦江区真实下级地名；ranking 正文六家平行结构完整；showcase 标题带品牌、ranking 标题不带且含当前年份。

## 样本 B：画像稀疏·仅必填 4 字段（测省略与降级）

```json
{
  "fullName": "晨风企业咨询工作室",
  "industry": "企业管理培训",
  "products": ["管理层培训"],
  "coreAdvantages": ["定制化课程"]
}
```

评审要点：正文不得补写门店/地址/电话/案例/资质；showcase 栏目省略而非编造；挖词画像块收缩但核心服务仍在；direct 标题在无 serviceArea 时不强制地域子串。

## 样本 C：非本地服务·多简称·有竞品（测行业迁移与简称规则）

```json
{
  "fullName": "深蓝智造软件科技有限公司",
  "shortNames": ["深蓝智造", "智造科技"],
  "serviceArea": "深圳市南山区",
  "industry": "制造业数字化咨询",
  "products": ["MES 系统实施", "工厂数字化诊断"],
  "coreAdvantages": ["交付过 40+ 家工厂", "自有实施方法论"],
  "competitors": ["甲科技、乙数字化、丙智造（三个合成竞品名）"],
  "targetCustomers": ["中型制造企业厂长", "IT 负责人"]
}
```

评审要点：prompt 不得隐含「本地门店/上门」预设（检测挖词与正文是否套用本地服务模板）；简称只取已确认两个，正文不得自造简称；B2B 语境的意图维度（资质/对比/效果）覆盖。

## 评审流程

1. 每个样本跑一次问题池 → 选题 → 3 篇不同类型正文（guide/ranking/showcase 至少各一）。
2. 记录每段产出的四维评分（1–5）与具体病句/同质化/格式违规摘录。
3. 断言式检查：正文过 `deterministicArticleReview` 零 blocking；标题过 `validateTitleCandidates`；问题池无「机械拼接推荐尾巴」病句（人工抽查）。
4. 结果记录在本文件末尾追加（日期 + 样本 + 分数 + 摘录），作为下一轮提示词调优的基线。
